# How to Customize the Logarithmic Axis of Blazor Charts

## Project Overview
This project serves as a quick-start example for developers who want to understand how to use logarithmic axes in Blazor charts using Syncfusion components. It demonstrates how chart data can be populated from a list, how different series types are applied, and how chart elements such as legends, data labels, and tooltips are enabled. The sample is focused on helping users visually represent data that spans a wide numeric range using a logarithmic scale.

The application is implemented as a Blazor WebAssembly app and is suitable for learning or reference purposes when working with advanced chart axis configurations.

## Features
- Demonstrates the use of a logarithmic axis in Blazor charts  
- Uses Syncfusion Blazor Chart components  
- Shows how to bind list-based data to chart series  
- Includes legends, data labels, and tooltips  
- Designed as a simple, easy-to-run sample project  

## Prerequisites
To run this application, you will need:
- Visual Studio 2022
- .NET SDK compatible with Blazor WebAssembly
- Basic knowledge of Blazor and C#

## Installation
1. Check out or download this project to a local directory on your machine.
2. Open the solution file using Visual Studio 2022.
3. Restore NuGet packages by rebuilding the solution.
4. Ensure all dependencies are resolved successfully.

## Usage
After building the solution, run the project from Visual Studio. The application will launch in a browser and display a Blazor chart configured with a logarithmic axis. You can review the source code to understand how axis settings, series data, legends, data labels, and tooltips are configured.
