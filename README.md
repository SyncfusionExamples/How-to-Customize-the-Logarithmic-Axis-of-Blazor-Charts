# How to Customize the Logarithmic Axis of Blazor Charts

## Overview

This sample demonstrates how to customize the logarithmic axis in the Syncfusion [Blazor Chart](https://www.syncfusion.com/blazor-components/blazor-charts) component. The application focuses on logarithmic-scale data visualization and shows how chart data can be rendered using a logarithmic axis instead of a standard numeric axis. This approach is useful when visualizing datasets with values that span multiple orders of magnitude, helping improve readability and interpretation of large-scale data variations.

The project is implemented as a Blazor application and provides a practical reference for configuring logarithmic-axis behavior within Syncfusion Blazor Charts.

## Key Features

- Demonstrates logarithmic-axis configuration in Syncfusion Blazor Charts.
- Shows how chart data can be displayed using logarithmic scale calculations.
- Demonstrates chart rendering with a customized logarithmic axis.
- Uses Syncfusion Blazor Chart components for logarithmic data visualization.
- Illustrates axis configuration scenarios associated with logarithmic scaling.
- References the logarithmic-axis implementation documented for Syncfusion Blazor Charts.
- Uses a dedicated Blazor application project (`CustomLogarithmicAxis.csproj`) to host the sample.

## Prerequisites

- Visual Studio 2022 or Visual Studio Code
- .NET SDK compatible with the project's target framework

## How to Run the Project

**Visual Studio 2022**

1. Clone or download this repository.
2. Open `CustomLogarithmicAxis.sln`.
3. Restore all NuGet packages.
4. Set the `CustomLogarithmicAxis` project as the startup project if required.
5. Build the solution.
6. Run the application using `Ctrl+F5`.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the repository root containing `CustomLogarithmicAxis.csproj`.

```bash
dotnet restore
dotnet run
```

4. Open the local application URL displayed after the application starts.
